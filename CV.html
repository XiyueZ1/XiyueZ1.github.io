Neural Decoding projects

Supervisor: Prof. Aysegul GunduzGainesville, FL, USA, Feb 2016 – Apr 2016

Analyzed monkey EEG signals using spike-sorting algorithms (PCA, k-means) and decoded EEG responses in a BCI P300 speller and a sensorimotor-rhythm-based cursor control task.

Supervisor: Prof. Parisa RashidiGainesville, FL, USA, Sep 2015-Dec 2015

Built a combined machine learning classification model to discern fMRI brain image data based on cognitive states (reading and resting-state). Evaluated the performance of multiple kinds of classifiers using different algorithms.
